# Android-liturgy-widget

Home-screen widget for Android that shows today's liturgical day twice:

- **Traditional, 1962 Missal:** day name, class (I–IV), Epistle/lessons and Gospel.
- **Modern, 1969 Missal:** day name, rank (solemnity, feast, memorial...), readings, psalm and Gospel.

Only book and verse numbers are shown. Tap the widget to open the app, which lists every lesson and every Mass of the day.

## Install

1. Open **Releases > Latest build** in this repository on the phone and download `liturgy-widget.apk`.
2. Allow your browser to install apps when Android asks. If Samsung **Auto Blocker** stops the install, turn it off under Settings > Security and privacy, then turn it back on afterwards.
3. Open the app once, then long-press the home screen > **Widgets** > **Liturgical Day**.

Every build is signed with the same key (`app/debug.keystore`), so a new APK installs over the old one without uninstalling.

## How the data stays current

- `data/liturgy.json` holds one entry per day. The APK carries a copy and the widget downloads the newest one from this repository at most once a day, so new data reaches the phone without a new APK.
- `.github/workflows/refresh-data.yml` runs monthly (and on demand under **Actions > Refresh data > Run workflow**). It runs `scripts/regenerate.py`, which rebuilds the window from 30 days ago to Dec 31 of next year, and commits the file if it changed.
- The 1962 side is computed by running Divinum Officium's code, so any future date works.
- The 1969 side comes from the catholic-readings-api dataset, which covers 2025 to 2027 as of Nov 2026. Dates it doesn't cover show "Not available yet" on the 1969 card until its author adds them. Entries already saved here are kept.

If the 1969 side is still empty for a date you need, that is the dataset's gap, not a bug in this repository.

## Build

GitHub builds the APK (`.github/workflows/build-apk.yml`). To build locally you need JDK 17, the Android SDK (platform 34) and Gradle 8.7: `gradle assembleDebug`.

## Data sources and licenses

- Divinum Officium (MIT): https://github.com/DivinumOfficium/divinum-officium. The 1962 Epistle and Gospel citations are generated by running its code under the 1960 rubrics.
- catholic-readings-api (MIT): https://github.com/cpbjr/catholic-readings-api. Its 1969 calendar and reading citations were collected from USCCB.
- Only citations (book, chapter, verse) are stored. No Scripture text is included.
- Book names are expanded from Divinum Officium's abbreviations by `scripts/regenerate.py`.
